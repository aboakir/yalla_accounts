سياسة الخصوصية — Yalla Accounts

نسخة اختبار C06 / مسودة ما قبل الإطلاق.

Yalla Accounts هو نظام إدارة وتشغيل وحسابات لورش إصلاح ودهان المركبات. صُمم التطبيق بأسلوب Local-first، ولذلك تبقى بيانات التشغيل والمحاسبة الأساسية على جهاز المستخدم ما لم يطلب المستخدم صراحةً تصديرها أو مشاركتها أو استخدام خدمة مستقبلية تدعم المزامنة.

البيانات التي يعالجها التطبيق

قد تشمل بيانات الورشة، المستخدمين، العملاء، المركبات، ملفات الإصلاح، الصور، المستندات، الدفعات، السجلات المحاسبية، النسخ الاحتياطية، وبيانات تقنية لازمة للأمان والترخيص.

بيانات الترخيص والأمان

عند التفعيل أو التحقق الدوري، يرسل التطبيق إلى خدمة ترخيص Yalla بيانات تقنية مثل معرّف المؤسسة، معرّف التثبيت والجهاز، المفتاح العام للجهاز وبصمته المشفرة، نسخة التطبيق، وحالة الترخيص. لا يرسل المفتاح الخاص للجهاز.

الكاميرا ومكتبة الصور

لا يستخدم التطبيق الكاميرا أو مكتبة الصور إلا عندما يختار المستخدم التقاط أو إرفاق صورة ضمن سجل في التطبيق.

الاحتفاظ والحذف

يمكن طلب حذف الحساب والبيانات الشخصية من صفحة «طلب حذف الحساب والبيانات». قد نحتفظ بسجلات محددة إذا كان الاحتفاظ بها ضروريًا للالتزامات القانونية أو المحاسبية أو لمنع الاحتيال، مع تقليل البيانات الشخصية حيثما أمكن.

مشاركة البيانات

لا تُشارك بيانات الورشة التشغيلية مع أطراف خارجية إلا عندما يطلب المستخدم ذلك (مثل التصدير أو المشاركة) أو عندما تكون الخدمة التقنية ضرورية لتشغيل وظيفة طلبها المستخدم، مثل التحقق من الترخيص.

التغييرات

قد تتغير هذه السياسة قبل الإطلاق التجاري النهائي. النسخة المنشورة مع الإصدار التجاري هي النسخة الملزمة.
